# CoH3 Build Advisor

An unofficial community-built Company of Heroes 3 build order and battlegroup advisor.

🌐 **Live tool:**  
https://gggerrit15.github.io/coh3-build-advisor/

## Features

- All four factions
- 1v1 / 2v2 / 3v3 / 4v4
- Battlegroup recommendations
- Matchup-specific advice
- Map context
- ELO context
- Creator build comparisons
- Battlegroup rankings
- Build order decision branches
- Tech / production legality checks

## Current Version

**CoH3 Build Advisor v8.6**

Current data is based around **Patch 2.5.3**.

## Important

This is an unofficial community project.

Not every build order represents an exact replay-derived modal build.
Some profiles are synthesized recommendations using available statistics,
creator builds, current unit tech requirements and matchup context.

Confidence levels are shown inside the tool.

## Data Sources / Method

The advisor uses a combination of:

- CoHDB build-order statistics
- CoH3Stats unit / battlegroup / tech information
- High-level creator builds
- Matchup and game-mode adaptation
- Manual production and tech legality checks

See the "Sources / Method" tab inside the advisor for additional information.
